---
title: Lean Oracle documentation
description: Real-time market data for CKB applications, signed every second and verified on chain.
---

Lean Oracle aggregates prices from leading exchanges. A committee of publishers signs them every second,
and your CKB application brings a signed price on chain whenever it needs one. The chain checks the
signatures, so no relayer or server has to be trusted.
