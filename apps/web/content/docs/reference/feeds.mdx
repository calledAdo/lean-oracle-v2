title: Price feeds

---

A feed ID is `ckb_hash("LEAN/FEED/V1" || symbol)`, for example of `Crypto.BTC/USDT`. The SDK accepts
a symbol or an ID anywhere a feed is expected. IDs are permanent.

<FeedTable />

- **Exponent.** A price is an integer: value = price × 10<sup>exponent</sup>.
- **Native pairs.** Each feed is priced only from markets that trade exactly that pair. Combine feeds
  for other pairs.
- **Update frequency.** Every second for `majors`, every two seconds for `ckb`.
- **Each price also carries** a confidence, an EMA price and confidence, the source data time and the
  number of publishers that contributed.
