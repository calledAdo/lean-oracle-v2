## What a publisher does

A publisher runs the publisher service (a Docker image), which:

- keeps live connections to every exchange its committees use;
- computes each feed's price every tick with the committee's rules;
- exchanges observations and signatures with the other publishers;
- signs one header per tick, never two, and serves finalized updates to mirrors.

## What it takes

- A reliable server with good connectivity to the exchanges.
- Secure key storage; the service supports a key file or AWS KMS.
- Monitoring and on-call attention, since a missing publisher weakens the quorum.
- Checking each exchange's market-data terms.

Committees hold up to nine publishers; the target is seven for `majors` and four for `ckb`.
