## Testnet

Deployed. These values come from the deployment record the SDK ships with
([`deployments/testnet.json`](https://github.com/calledAdo/lean-oracle-v2/blob/main/deployments/testnet.json)),
so they always match what `LeanOracleTestnetClient` uses. Click a value to copy it.

<NetworkTable />

All contracts use `hash_type = data2` and have no upgrade key. A fix is a new deployment with a new
code hash; earlier versions stay listed in the record.
